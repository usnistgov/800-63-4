# Special Publication 800-63 _Digital Identity Guidelines_ Revision 4

The finalized four-volume SP 800-63-4 _Digital Identity Guidelines_ is now available, both in PDF format and online.

The official versions of these documents are the PDFs available at:

- <https://doi.org/10.6028/NIST.SP.800-63-4>
- <https://doi.org/10.6028/NIST.SP.800-63a-4>
- <https://doi.org/10.6028/NIST.SP.800-63b-4>
- <https://doi.org/10.6028/NIST.SP.800-63c-4>

An HTML version of the document suite is available at NIST Pages website at <https://pages.nist.gov/800-63-4/>.

This repository is available as a resource for those who prefer to view the documents in HTML form.

While this is believed to be a faithful representation of the official PDF documents, NIST would appreciate being informed about any inconsistencies that may be found other than minor formatting differences. These may be reported to dig-comments@nist.gov.
